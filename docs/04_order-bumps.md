# 04 — Order bumps e upsell

Order bump = oferta extra com caixinha de marcar dentro do checkout. É onde está o lucro.

## Regras

- **3 a 5 bumps** por oferta. Cada um complementa o produto principal (não repete).
- Preço do bump: **R$ 9,90 a R$ 27**. Soma de bumps pensada para levar o ticket a R$ 90+.
- Título do bump em uma linha, começando pelo benefício. Descrição em até 2 frases.
- Ordem: o bump mais barato e mais óbvio primeiro (maior taxa de aceite).
- Upsell pós-compra (1 clique) opcional: R$ 37 a R$ 97, versão "completa/avançada".

## Tipos que funcionam

| Tipo | Exemplo (produto principal: planilha de orçamento) |
|---|---|
| Versão pronta/preenchida | Planilha já preenchida com exemplo real |
| Atalho | Checklist de 1 página para usar no dia a dia |
| Expansão | Pacote de 12 planilhas mensais + anual |
| Formato diferente | Versão para imprimir / versão para celular |
| Bônus de urgência | Guia "primeiros 7 dias" |
| Acesso vitalício a atualizações | Novas versões sem custo |

## Exemplo de conta

| Item | Preço | Aceite esperado | Receita média |
|---|---|---|---|
| Produto principal | R$ 47,00 | 100% | R$ 47,00 |
| Bump 1 | R$ 14,90 | 45% | R$ 6,71 |
| Bump 2 | R$ 19,90 | 35% | R$ 6,97 |
| Bump 3 | R$ 27,00 | 25% | R$ 6,75 |
| Bump 4 | R$ 17,00 | 30% | R$ 5,10 |
| **Ticket médio** | | | **≈ R$ 72,50** |

Para passar de R$ 90 é preciso bumps mais desejados (aceite maior) e/ou um upsell.
As taxas de aceite acima são hipóteses: substitua pelos números reais de cada oferta.
